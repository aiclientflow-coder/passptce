# Medications Domain — PassPTCE Original Study Notes

Domain weight: ~35% of PTCE (2026 outline). Technician scope: recognition, classification, dosage forms, schedules awareness, high-alert flags, and counseling *points* you may reinforce after pharmacist counseling — not diagnosing or choosing therapy for a patient.

## Brand / generic fluency

Memorize pairs by class, not random lists. Exam stems often give one name and ask for the other, or ask which drug is in a class.

### Cardiovascular
- Atorvastatin → Lipitor (HMG-CoA reductase inhibitor / statin)
- Simvastatin → Zocor; Rosuvastatin → Crestor; Pravastatin → Pravachol
- Lisinopril → Prinivil / Zestril (ACE inhibitor). Watch for dry cough as a counseling point class effect.
- Losartan → Cozaar; Valsartan → Diovan (ARBs)
- Amlodipine → Norvasc (dihydropyridine CCB)
- Metoprolol tartrate → Lopressor; Metoprolol succinate → Toprol-XL (beta blockers; salt forms are not interchangeable casually)
- Carvedilol → Coreg; Atenolol → Tenormin
- Clopidogrel → Plavix (antiplatelet P2Y12)
- Warfarin → Coumadin / Jantoven (vitamin K antagonist; high-alert; INR monitoring)
- Apixaban → Eliquis; Rivaroxaban → Xarelto (DOACs; high-alert anticoagulants)
- Furosemide → Lasix (loop diuretic); Hydrochlorothiazide → Microzide (thiazide)
- Spironolactone → Aldactone (potassium-sparing; hyperkalemia awareness)

### Endocrine / diabetes / thyroid
- Metformin → Glucophage (biguanide; GI upset common counseling point)
- Glipizide → Glucotrol; Glyburide → Diabeta (sulfonylureas; hypoglycemia risk)
- Sitagliptin → Januvia (DPP-4)
- Empagliflozin → Jardiance; Dapagliflozin → Farxiga (SGLT2)
- Semaglutide → Ozempic / Rybelsus / Wegovy (GLP-1; brand depends on indication/form)
- Insulin glargine → Lantus / Basaglar / Toujeo (basal; high-alert)
- Insulin lispro → Humalog; Insulin aspart → NovoLog (rapid-acting; high-alert)
- Levothyroxine → Synthroid / Levoxyl / Tirosint (narrow therapeutic index; take consistently, often empty stomach)
- Methimazole → Tapazole (antithyroid)

### CNS / pain / psych
- Sertraline → Zoloft; Fluoxetine → Prozac; Escitalopram → Lexapro (SSRIs)
- Duloxetine → Cymbalta; Venlafaxine → Effexor XR (SNRIs)
- Alprazolam → Xanax; Lorazepam → Ativan; Diazepam → Valium; Clonazepam → Klonopin (benzodiazepines; C-IV)
- Zolpidem → Ambien (C-IV)
- Gabapentin → Neurontin; Pregabalin → Lyrica (Lyrica is C-V federally)
- Amphetamine/dextroamphetamine → Adderall; Methylphenidate → Ritalin / Concerta (stimulants; often C-II)
- Oxycodone → OxyContin / Roxicodone; Hydrocodone/APAP → Norco / Vicodin (legacy); Morphine; Fentanyl (C-II opioids; high-alert)
- Tramadol → Ultram (C-IV federally)
- Acetaminophen → Tylenol (hepatotoxicity with overdose; OTC counseling limits)
- Ibuprofen → Advil / Motrin; Naproxen → Aleve (NSAIDs; GI / kidney / bleed risk awareness)

## Therapeutic class recognition

Exam skill: map drug → class → typical use (technician level).
- Statins: LDL cholesterol reduction
- ACEI / ARB: hypertension, heart failure contexts
- Beta blockers: rate control, hypertension, post-MI contexts
- Biguanide: type 2 diabetes first-line familiar agent
- PPI: acid suppression (GERD / ulcer contexts)
- SSRI: depression / anxiety contexts
- SABA: rescue bronchodilation
- Antibiotics: treat bacterial infection — never viral colds (counseling reinforcement only)

## Dosage forms and routes

Know what the form implies for handling and patient use:
- Tablets / capsules: oral solid; some cannot be crushed (extended-release, enteric-coated)
- Solutions / suspensions: shake suspensions; measure with calibrated device
- Creams / ointments / gels: topical; potency and base differ
- Patches: transdermal; rotate sites; do not cut unless product allows
- Inhalers / nebulizer solutions: technique matters (pharmacist counseling)
- Injectables: SQ / IM / IV — pharmacy tech may prepare or hand off per site policy; insulin pens vs vials
- Suppositories: rectal / vaginal
- Ophthalmic vs otic: eye vs ear — never assume interchangeable
- Buccal / sublingual: absorb in mouth; do not swallow immediately if directed otherwise
- ER / XR / SR / CR / LA: modified release — generally do not crush or chew

## Controlled substance schedule awareness (medication lens)

Recognition only — federal scheduling concepts:
- C-II: high abuse potential with accepted medical use (many potent opioids, most ADHD stimulants). No federal refills on C-II (new Rx required).
- C-III: e.g., some combination products historically; anabolic steroids federally C-III
- C-IV: benzodiazepines, zolpidem, tramadol (federal)
- C-V: e.g., pregabalin; some cough preparations with limited codeine (federal rules + state)
- Schedule I: no accepted medical use federally (exam recognition; not dispensed as legitimate Rx in usual outpatient practice)

## REMS (technician awareness)

Risk Evaluation and Mitigation Strategies exist for certain high-risk drugs. Techs should recognize that extra steps (certification, documentation, restricted distribution) may apply. Classic awareness examples often discussed in training: isotretinoin (iPLEDGE-type requirements historically), some opioids, clozapine monitoring programs. Exact portal workflows are site-specific — exam tests *concept*: REMS = extra safety requirements beyond standard labeling.

## High-alert medication flags

High-alert ≠ most prescribed. Means heightened risk of significant harm if used in error:
- Insulins
- Anticoagulants (warfarin, heparins, DOACs)
- Opioids
- Concentrated electrolytes (institutional)
- Chemotherapeutic agents (institutional / specialty)
- Some hypoglycemics

Technician behaviors: careful product selection, barcode when available, respect independent double-checks, flag look-alike packaging.

## Side effects / counseling points (tech reinforcement)

You do not replace the pharmacist. You *do* recognize common class points that appear on exams:
- ACE inhibitors: dry cough; angioedema is emergency
- Statins: muscle pain — report; grapefruit interaction awareness for some agents
- Warfarin: bleeding signs; vitamin K consistency; many drug/food interactions
- Metformin: GI upset; rare lactic acidosis risk discussion is pharmacist-level nuance
- Opioids: sedation, constipation, respiratory depression risk
- Benzodiazepines: sedation, dependence risk
- Fluoroquinolones: tendon / CNS warnings awareness
- Tetracyclines: photosensitivity; chelation with cations
- Bisphosphonates: upright posture, full glass of water
- Inhaled corticosteroids: rinse mouth to reduce thrush risk

## Narrow therapeutic index (NTI) awareness

Small dose/level changes can cause failure or toxicity: warfarin, levothyroxine, digoxin, lithium, carbamazepine, phenytoin, tacrolimus (specialty), some others. Extra care with product selection and patient questions → pharmacist.

## Study tactics for this domain

1. Drill brand↔generic in class clusters 10 minutes daily.
2. For each top drug, say out loud: class, one use, one counseling flag, schedule if controlled.
3. Practice distinguishing similar endings: -pril ACEI, -sartan ARB, -olol beta blocker, -statin, -prazole PPI, -oxetine/-pram often antidepressant context.
4. If unsure on exam, eliminate wrong schedules and wrong classes first.
