# Order Entry & Processing — PassPTCE Original Study Notes

Domain weight: ~22% of PTCE (2026 outline). Skills: interpret directions, calculate days supply and basic doses, understand NDC structure, refills/transfers at federal awareness level, and insurance adjudication basics.

## Sig code interpretation

Common Latin-derived abbreviations (know expansions cold):
- po = by mouth; pr = rectally; pv = vaginally; sl = sublingual; ou = both eyes; od = right eye; os = left eye; au/ad/as = ears analogously
- qd / daily; bid = twice daily; tid = three times daily; qid = four times daily
- qhs = at bedtime; ac = before meals; pc = after meals; prn = as needed
- q4h / q6h / q8h / q12h = every N hours
- gtt = drop; tsp = teaspoon (5 mL); tbsp = tablespoon (15 mL)
- ung = ointment; AAA = apply to affected area (confirm site policy on abbreviations)
- NKDA = no known drug allergies

Safety: prefer plain English on labels when possible; still must *read* codes on exam. Ambiguous abbreviations → clarify with pharmacist/prescriber.

## Days supply calculations

**Oral solids:** days supply = (quantity) / (doses per day)

Example: 90 tablets, 1 tab po bid → 90 / 2 = 45 days.

**PRN caveats:** if max frequency given, insurers often calculate by maximum possible use; follow stem instructions.

**Insulin / injectables:** need units per day and units per container.
Example teaching pattern: vial 1000 units, patient uses 40 units/day → 1000/40 = 25 days (ignore overfill unless stem says).

**Inhalers / drops:** need sprays per device and sprays per day; eye drops often estimated (~15–20 drops/mL teaching rule of thumb — use the number the stem gives).

**Topicals:** days supply may be estimated; exam usually gives enough numbers.

## Dosage calculation patterns

Keep units consistent. Dimensional analysis reduces errors.

**mg → tablets:** ordered mg / strength mg per tablet = tablets per dose.

**Liquid:** (ordered mg / concentration mg per mL) = mL per dose.

**mg/kg:** weight (kg) × mg/kg = mg dose. Convert lb → kg: lb / 2.2.

**Percent solutions:** 1% = 1 g / 100 mL = 10 mg/mL (useful bridge).

**Ratio strengths:** 1:1000 epinephrine = 1 g / 1000 mL = 1 mg/mL.

Always double-check trailing zeros and decimal placement — classic error source.

## NDC structure

National Drug Code segments (10- or 11-digit billing formats):
- **Labeler code**: manufacturer / packager
- **Product code**: strength / dosage form / formulation
- **Package code**: package size / type

Billing systems often use 11-digit zero-padded NDCs. Matching NDC on stock bottle to Rx selection prevents wrong product.

## Refills and transfers (federal awareness)

- Non-controlled: refills as authorized; transfers between pharmacies generally permitted with remaining refills under federal teaching (state/Board rules apply).
- C-II: no federal refills; new prescription required for more supply. Transfer of unfilled C-II electronic prescriptions has specific modern rules — exam may test conservative “C-II tightly restricted” concept.
- C-III–V: limited refill windows federally (commonly taught 6-month / 5-refill pattern for III/IV).
- Partial fills: allowed in various situations (stock shortage, patient request, LTC) with documentation — pharmacist oversight.

## DAW codes (awareness)

Dispense as written codes communicate brand/generic selection intent for billing (e.g., DAW 0 = no product selection preference; DAW 1 = substitution not allowed by prescriber). Exact code list memorization varies — know *why* DAW matters: reimbursement and what product you may dispense.

## Insurance / adjudication basics

- Submit claim → payer responds paid / rejected / deferred.
- Common reject themes: refill too soon, invalid NDC, prior authorization required, quantity limits, non-covered drug, patient not covered / DOB mismatch.
- Tech role: read reject message, fix demographic/NDC/day-supply issues when appropriate, escalate clinical PA / therapy issues to pharmacist.
- Coordination of benefits if dual coverage.
- Never “force” a claim in a way that creates fraud; accurate information only.

## Workflow order (typical retail)

1. Receive Rx (e-Rx / written / fax per law)
2. Profile review / allergy / duplication flags (pharmacist clinical check)
3. Product selection / counting / pouring
4. Label generation
5. Technician accuracy check
6. Pharmacist final verification
7. Patient counseling offer / pickup ID as required

## Packaging and labeling

- Child-resistant containers unless patient/prescriber requests otherwise (federal Poison Prevention Packaging Act theme).
- Unit-dose / blister for some settings.
- Auxiliary labels: Take with food, May cause drowsiness, Shake well, For the eye, Refrigerate, etc.
- Medication guides / Patient Package Inserts for selected drugs — provide when required.

## Inventory processing links

- FIFO / FEFO: first expiry first out.
- Quarantine damaged / recalled / suspect DSCSA stock.
- Controlled substances: perpetual inventory practices often used for C-II.

## Study tactics

- Drill 20 sig codes daily until instant.
- Do 10 days-supply problems: tablets, liquids, insulin.
- Practice lb→kg and mg/kg once per session.
- Explain NDC segments aloud.
- Map insurance reject → first tech action.
